Erste Einrichtung

GitHub Repository Secrets einrichten:

Damit die Admin-Anmeldung funktioniert, müssen folgende GitHub Repository Secrets gesetzt werden:

ADMIN_USERNAME – Ihr gewünschter Benutzername
ADMIN_PASSWORD_HASH – SHA-256 Hash Ihres Passworts

Den SHA-256 Hash können Sie im Terminal erzeugen:
echo -n "IhrPasswort" | sha256sum

Nach dem Setzen der Secrets muss die Website neu gebaut werden (GitHub Actions).
GitHub Personal Access Token:

Um Änderungen zu speichern, wird ein GitHub Personal Access Token (PAT) benötigt. Erstellen Sie einen unter:
GitHub → Settings → Developer settings → Personal access tokens

Benötigte Berechtigung: repo (Vollzugriff auf Repositories).
Der Token wird nur für diese Browser-Sitzung gespeichert und beim Schließen des Tabs gelöscht.
Workflow nach dem Speichern:

Nach dem Speichern wird ein Commit in das GitHub-Repository übertragen. GitHub Actions baut die Website automatisch neu und veröffentlicht die Änderungen. Dieser Vorgang dauert ca. 1–2 Minuten.
